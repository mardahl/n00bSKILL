# Serviceafsnit audit

Use when finishing a report or auditing its support sections.

Check which support sections are required by local rules and report length:

- `Forside`
- Optional `titelblad` or `kolofon`
- `Indholdsfortegnelse`
- `Resumé`
- `Forord`
- `Kildefortegnelse`
- `Bilag`
- `Bilagsfortegnelse` when appendices are numerous

`Serviceafsnit` are the report's `brugsanvisning`, not decoration:

- Remove unreferenced `bilag`; appendices included to show effort go out.
- Reference every appendix from the main text.
- Match table-of-contents depth to report length.
- Local `formalia` override generic guidance — ask for `retningslinjer`, rubric, template, page count, citation style, and layout rules before finalizing.
